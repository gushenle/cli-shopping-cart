# 🛒 命令行购物车系统

**[English](README.en.md) | 中文**

一个基于 Node.js 的简单命令行购物车系统。用户通过命令行界面（CLI）浏览商品、加入购物车并完成结账，核心逻辑使用 [Vitest](https://vitest.dev/) 编写单元测试验证。

## 功能特性

- **商品列表**：预置多个商品，每个商品包含 `id`、名称、描述、价格和可用数量
- **加入购物车**：输入商品 ID 和数量将商品加入购物车
- **购物车管理**：购物车以数组表示，条目含 `productId`、`quantity`、`totalPrice`
- **结账流程**：计算总价、减少库存并清空购物车
- **循环交互**：每次操作后回到商品选择，可连续加入多件商品
- **单元测试**：使用 Vitest 全面验证核心函数与边界情况

## 命令行使用说明

启动后系统会显示商品列表，并提示输入操作：

| 输入 | 说明 |
|------|------|
| `商品ID 数量` | 将商品加入购物车，例如 `1 2` 表示加入 2 件商品 ID 为 1 的商品 |
| `cart` | 查看当前购物车内容与合计金额 |
| `checkout` | 结账：计算总价、减少库存并清空购物车 |
| `quit` / `exit` | 退出系统 |

## 核心函数 API

核心逻辑位于 [src/cart.js](src/cart.js)，均为纯函数并接收 `products` 数组作为参数，便于测试状态隔离：

| 函数 | 说明 |
|------|------|
| `findProduct(products, productId)` | 按 ID 查找商品，找不到返回 `undefined` |
| `addToCart(products, cart, productId, quantity)` | 加入购物车，同名商品合并数量并重算 `totalPrice`；对无效输入抛错 |
| `calculateTotal(cart)` | 计算购物车总价，空购物车返回 `0` |
| `checkout(products, cart)` | 计算总价、减少库存、清空购物车并返回总价 |

商品数据位于 [src/products.js](src/products.js)，导出 `createProducts()` 工厂函数（测试用独立状态）与默认 `products` 列表。

## 测试覆盖

[test/cart.test.js](test/cart.test.js) 共 12 个测试用例，覆盖以下场景：

- 查找存在的商品 / 查找不存在的商品
- 将商品加入购物车（校验条目结构）
- 同名商品重复加入时的合并与价格重算
- 加入不存在的商品（抛错）
- 加入超过可用数量的商品（抛错）
- 数量为 0、负数、非整数的校验（抛错）
- 空购物车总价计算
- 多商品总价计算
- 空购物车结账（抛错）
- 结账流程：总价计算、库存减少、购物车清空
